# Contact Us Page

A semantic HTML5 contact page containing a structured form (`contact.html`) built with standard form elements and clean semantic structure.

## Features

The form includes the following HTML elements:

* Text Input: Single-line field for names.
* Email Input: Field with built-in format validation.
* Number Input: Field restricted to numeric values.
* Date Input: Native date picker for date selection.
* Radio Buttons: Grouped options for single selection.
* Checkboxes: Options allowing multiple selections.
* Dropdown Menu: Select menu for choosing options.
* Text Area: Multi-line field for long messages.
* Navigation Bar: Navigation links for site pages.
* Semantic Markup: Structured with header, nav, main, section, and footer elements.
